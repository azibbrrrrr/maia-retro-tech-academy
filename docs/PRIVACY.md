# Privacy

Visitors move their own ephemeral explorer. There is no tracking, analytics,
registration, chat, visitor-to-teacher messaging or persistent visitor identity.
The teacher is a stationary fictional scripted character with the requested
display name Ustazah Juliana; no real school, employer, likeness or biography is
represented. All dialogue is local curated text.

The demo whiteboard contains educational examples only. No private repository
names, counts, titles, URLs, source code, terminal sessions or agent prompts are
collected or displayed. Agents are offline; nothing implies a live coding session.

The local operator password is server-side and is not logged. This initial
operator has no GitHub data. Future collectors require explicit repository
selection and separate public-projection review.

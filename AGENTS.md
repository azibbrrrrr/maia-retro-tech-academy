# Academy engineering boundaries

This is an independent personal, unofficial showcase. Never import workplace
source, customer data, private repository details, secrets or production connections.

- Public service: loopback port 3000, read-only, demo by default.
- Operator: separate process and build, loopback port 3100, authentication required.
- Never mount operator routes, agent gateways, terminals or execution on public.
- No private metadata or counts may reach visitors. Future integration requires a
  server-side allowlist serializer with adversarial tests before connection.
- Teacher Ustazah Juliana is a fictional display identity, stationary scripted NPC,
  never an agent. No real school, photos, identifying biography or communications.
- Every external asset needs redistribution evidence. No Agent Town files or
  purchased tilesets. Keep original placeholder graphics until Sprint 0 passes.
- Keep demo, offline, stale and live explicit. Never invent live activity.
- Run typecheck, lint, tests, browser tests, build, dependency and secret scans.
- Do not tunnel the development server. Public deployment requires release gates.

Commits are authored by Azib. Never add attribution or co-author trailers.
Use `type(scope): lowercase imperative subject`, at most 72 characters, no final
period, one change per commit. Types: feat, fix, docs, refactor, test, chore, perf,
build, ci. Optional body: at most three short why bullets, wrapped at 72 columns.
